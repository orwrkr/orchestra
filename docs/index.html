A multi-model orchestrator for Claude Code

Your Claude Code session breaks a task down and decides who does each subtask, and at what effort: Claude subagents, Codex CLI, DeepSeek, or a pool of tasks for manual agents. Routing follows each model's strengths, your subscription limits and balance, and the rules you set per project.

claude plugin install partitura --marketplace orwrkr/partitura

Who does the work

  • Claude subagents

    Haiku, Sonnet, Opus and Fable, each at the effort level the subtask needs, inside your session.

  • Codex CLI

    On your ChatGPT subscription or an API key, in the background, in its own sandbox.

  • DeepSeek

    On an API key, as a full agent: headless Claude Code on DeepSeek's Anthropic-compatible API, paid from your balance.

  • Manual task pool

    Tasks for Antigravity, Cursor and similar agents. You pick a task and paste one line. Partitura never drives these apps itself: it only writes task files and reads results.

What it takes into account

  • Model registry

    Difficulty, cost and strengths per model and effort, with cross-review between model families for significant code.

  • Subscription limits

    Limits and balances you report in plain words, or that executors report themselves. When the Claude 5-hour window would expire largely unused, Claude takes work that would otherwise cost money.

  • Spend limits

    USD caps for API-billed executors (orch spend): a manual counter for prepaid keys, a monthly budget otherwise.

  • Executor profiles

    Per project: which key or account, which models, which rules, or off.

  • Usage log

    Which model did what in each session, and how many tokens it spent (orch usage).

  • DeepSeek as the lead

    orch launch deepseek runs the same setup with DeepSeek orchestrating, optionally with Claude switched off.

Install

Requires Claude Code, Python 3.8 or newer (standard library only) and git. Codex CLI and a DeepSeek API key are optional.

Option 1 — The plugin only

claude plugin install partitura --marketplace orwrkr/partitura

Option 2 — From a clone

Also puts orch in your terminal (needed for orch launch).

git clone https://github.com/orwrkr/partitura && cd partitura && bash install.sh

Then start claude in your project and run /partitura:status. orch doctor shows what is available.

It works with Claude Code on WSL, Linux and macOS, and natively on Windows.

Your data

No telemetry. Hooks and the status line work on your machine. orch makes one network request of its own: your DeepSeek account balance (ORCH_BALANCE=off turns it off).

Each executor sends the task, the project rules and the files it reads to its own provider, on your account.
